CORRECTNESS AND THE EMPTY/NO-VALUE FLAG

The saved field named "abstained" is a syntactic empty/no-value flag. It does
not establish that the agent refused a question or that an execution failed.
In particular, returning no value is correct when the reference result is empty.

Frozen per-question flag             Correct    Incorrect    Total
Flag not set (answer provided)         1,834          443     2,277
Flag set (empty/no-value)                422          232       654
All accepted outcomes                 2,256          675     2,931

All 422 correct flagged outcomes have empty references; 416 have a null final
answer. Thus the 654 flagged outcomes must not be described as 654 failures or
refusals. Overall accuracy includes these correct empty-reference outcomes.

Descriptive answer coverage, defined as flag not set, is 2,277/2,931 = 77.6868%.
Conditional accuracy among those 2,277 outcomes is 1,834/2,277 = 80.5446%.
That selected-subset statistic does not replace the overall 76.9703% accuracy.
Neither flag nor correctness was used to choose reruns.
