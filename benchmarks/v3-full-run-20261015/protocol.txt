frozen setup. Original-paper aggregate scores cannot replace a matched control

Runtime recovery policy
The user's current instructions replace earlier experiment notes that counted
every first-attempt provider failure as wrong or required another subset gate.
Preserve immutable raw attempts. Retry only explicit infrastructure failures,
including provider/network timeouts and service unavailability, without using
gold labels, correctness or a favorable answer to decide eligibility. Include
auxiliary contract/audit phase failures even when the primary was preserved.
The accepted result is the first completed attempt without runtime failure.
Completed incorrect answers, legitimate empty answers, abstentions, malformed
agent outputs, source-check failures and exhausted design budgets are final
outcomes. Unknown failures require investigation instead of silent scoring.
Unresolved runtime failures remain pending; never convert them into wrong rows.
Retries use the same frozen question, model/settings, architecture and budgets.

Primary time and cost
Per-question latency and token usage belong only to the accepted attempt;
earlier runtime attempts are excluded from primary accuracy, time and cost.
Operational records retain retry counts and failures independently. Summed
question latencies differ from elapsed parallel benchmark wall time: report
both with explicit labels. Missing usage/cost stays unknown, never zero.

The user authorized official OpenAI prices, assuming the Azure deployment has
the same prices. Adopt GPT-6 Luna standard short-context rates, USD per million:
uncached input 0.10, cached input 0.01, output 0.50. The 32k request input guard
keeps requests in the short-context band. Calculate estimated cost as
((prompt-cached)*0.10 + cached*0.01 + completion*0.50)/1,000,000.
This is a usage-based estimate, not a provider billing receipt. Preserve the
schedule and source URLs in pricing.json, and raw per-call usage for recalculation.

Interpretation
The full released cohort includes development-exposed questions and patients.
It is descriptive full-cohort performance, not a fresh held-out confirmation of
design superiority. Record original split/exposure labels for subgroup analysis.
Source-valid answers can still be semantically wrong. Model-shared errors and
cohort reuse limit any causal claim about independent verification or topology.
The full ordinary run does not establish the separate missing-evidence recovery
experiment or repeated-run variability; those require their own data.

Monitoring and preservation
Freeze exact inference/source hashes, input/manifests, public provider settings,
runtime adapter/bootstrap, package versions, launch commands and timestamps.
Never record credentials or read secret-bearing files during manual inspection.
The configured launcher may read credentials internally during authorized runs.
Monitor accepted/pending/retry counts, owned process health, recent progress,
source integrity, audit references and disk headroom. Use checkpoints to resume
after runtime interruptions without repeating completed model/design outcomes.
Save final accepted tables, summary/report, operational logs and their hashes.
