Hidden labels and verification

run_agent.py dispatches only question_with_context strings to agents.
Reference answers are retained in evaluation/result rows and scorer-side
data; the agent dispatch does not send those labels to the model. The
inspected production reasoning/retrieval code does not use gold answers or
gold resource identifiers to make runtime choices.

Production MultiAgentSystem constructs VerificationAgent with
require_explicit_final=True. Its legacy auto-mode compatibility for older
unit tests therefore does not bypass the production final-execution gate.
The verifier prompt is candidate-blind. Source checks, complete independent
execution, metadata validation, scoped citations and unchanged private
workspace/question identity remain necessary for certification and reuse.
Scope or budget failures do not establish supported absence.

Early execution observations

At the inspected snapshot, 128 of the 300 scheduled single-agent rows had
recorded token measurements. There were no observed 200,000-token or
30-tool ceiling overruns. Seven attempts recorded budget stops, and one
recorded a provider timeout. The timeout remains a first-attempt outcome;
it must not be retried to improve the benchmark score. The team arm had
not yet produced its output file. No partial accuracy comparison was made.

Material recording limitation

Both arms call the shared patient-rooted Medication dependency helper.
However, the single agent's inherited retrieval dispatcher converts its
result to a resource-handle/count string and discards retrieval_metadata.
Its trace therefore does not record the helper's physical request/page
counts or cache-hit metadata. The team Toolbox preserves that metadata.
The early single trace had zero such metadata replies.

Consequently, physical Medication request/page/cache accounting is not
symmetrically observable in the two saved arm traces. The design should
report this coverage limitation rather than claim complete physical-path
audit coverage for both arms. This does not change the shared logical
30-tool ceiling or the implemented Medication closure strategy.

Conclusion

No fatal protocol issue was found in the inspected frozen source and early
execution rows. The asymmetric physical-request logging is a material
reporting caveat. Runtime edits are deferred until the comparison finishes.
